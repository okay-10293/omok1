# 맞고

친구와 1:1로 하는 맞고. 서버 없이 브라우저끼리 직접 연결(PeerJS/WebRTC)돼요.

## 하는 법

1. 한 명이 `방 만들기` → 5자리 코드가 나와요.
2. 다른 한 명이 코드를 입력하고 `입장`.
3. 입장하면 바로 시작. 방장이 먼저 칩니다.

## 배포

저장소 Settings → Pages → Branch `main` / root 로 켜면 `https://<아이디>.github.io/<저장소>/` 에서 열려요.

## 규칙 (간단 버전)

- 패 10장씩, 바닥 8장, 더미 20장
- 같은 월 패끼리 매칭해서 가져감 (바닥에 2장이면 하나 선택)
- 7점부터 고/스톱
  - 광: 3광 3점(비광 포함 2점), 4광 4점, 5광 15점
  - 열끗 5장부터 1점 + 장당 1점, 고도리 5점
  - 띠 5장부터 1점 + 장당 1점, 홍단/청단/초단 각 3점
  - 피 10장부터 1점 + 장당 1점 (쌍피 2장)
- 고: 1고 +1, 2고 +2, 3고부터 ×2, ×4…
- 뻑/쪽/폭탄/흔들기/박 없음

## 로컬 실행

`index.html`을 열기만 하면 돼요. (`game.js`와 같은 폴더)
